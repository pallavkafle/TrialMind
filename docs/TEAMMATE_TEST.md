# TrailMind: Tester Guide

Install `app-debug.apk` on your phone (allow "install unknown apps"). You can use mobile data or any Wi-Fi—the server is online at `https://trailmind.pallavkafle.com.np` while the owner's PC is running.
Account: Register your own (Sign up) or use `demo@example.com` / `Demo@1234`.

## Try These (About 20 minutes)
1. Register with your country; log in; log out; log in again
2. Home > Plan My Trip > AI Trip Guide: describe a trip in your own words, check "Here's what I understood", change something, Create itinerary
3. Save the trip; open it in My Trips; delete it
4. Budget: Pokhara to Everest Base Camp, 12 days, group 4, October, Foreign: note the total
5. Permits: Everest Base Camp, then Manaslu Circuit
6. Places > open a place > weather, reviews > write a review > delete it
7. Heart a place; Saved Places; Profile (change name and country); Settings (theme)
8. Emergency (Nagarkot), Hotels (Pokhara), Map (turn Hospitals on)
9. Turn mobile data off and open Places: you should see the "Offline: showing saved data" pill
10. Anything that looks wrong, slow, cut off or confusing

If a message ends with (530), (502) or (524) the owner's PC or tunnel is off: message the owner and retry later.
